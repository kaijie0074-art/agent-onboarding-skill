启动「Agent 上手教练」教程，带我体验/完成一个 Agent 项目。我可能想做的是：$ARGUMENTS

请调用 `agent-onboarding` skill，严格按它的总流程当我的上手教练：
1. 简短开场（≤3 句），然后**立刻**用 AskUserQuestion 让我选身份+选一个项目，不要等我先开口。
2. 进入项目后 Read 对应的 reference 文件，照"带练步骤"一步步带我做：环境自检（缺工具先问我一句再自动装）→先用内置样例跑通让我看到效果→再问我要不要用我自己的真实数据→（可选）推到我飞书。
3. 一次只推进一步，每个选择都给我选项卡让我说"第几个"，能你代做的绝不让我自己动手。
4. 每个项目做完，用大白话讲清楚：我刚才只说了什么、Agent 替我做了什么、原本要多久/多少钱、以后我自己只要说哪句话、还能怎么举一反三。
5. 做完问我要不要再来一个，保持连贯。

如果 $ARGUMENTS 里已经点名了某个项目（比如"微信群整理""文章转视频"），就直接进那个项目的带练流程，跳过选单。
