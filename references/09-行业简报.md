# 项目 09 · 每周行业简报（联网刷一遍行业，每条配"对你意味着什么"）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
每周自动帮你刷一遍行业，挑出值得关注的动态，每条配"这对你意味着什么"。

## 适合谁
想跟上行业但没空刷资讯的创业者 / 从业者。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
**「我关注【某某赛道】，帮我出一份本周（先帮我把"本周"锁定成具体日期范围）行业简报：5–8 条动态、每条配一句对从业者的意义、一个深挖趋势、行动建议。每条都要点进原文核对发布日期、标来源链接；如果数据是更早发布的要标出来，别把旧闻说成本周；开头提醒我'AI 可能编造链接，请点开核对'。」**

## 环境自检（开始前，教练静默判断）
- 🟢 联网内置、零准备：本项目只需要联网搜索 + 抓取网页，模型自带，无需安装任何工具。
- 唯一前置：当前环境要能联网（见下方"Claude Code vs Codex"）。

## 准备输入（开始前）
- 让用户说出他关注的赛道（例如"跨境电商""AI 编程工具""新茶饮""预制菜"）。
- 用户说不出 / 只想先看效果 → 用一个通用赛道（如"AI 编程工具"）先演示。

## 带练步骤（一步一句，做完回报再走下一步）
1. 问用户：**先拿一个赛道演示，还是直接出你关注赛道的简报？**（AskUserQuestion）
2. 先把"本周"锁定成具体日期范围（如"6 月 2 日—6 月 8 日"），并念给用户确认这就是他要的口径。
3. 联网多源搜索该赛道近期动态（多个来源交叉，别只信一处）。
4. 逐条 WebFetch 点进原文，核对每条的**真实发布日期**——只有落在锁定日期范围内的才算"本周"。
5. 从核对过的里面挑出本周 5–8 条要点。
6. 每条配上"对从业者的意义"（一句话）+ 来源链接。
7. 给一个"深挖趋势"段落 + 几条"行动建议"。
8. 在简报开头加一句提示："AI 可能编造链接，请点开核对"。回报成果路径。

## 成功标准
简报里都是真正落在本周日期范围内的真实动态、来源链接能点开打开、不在本周的旧数据有明确标注（"此数据发布于 X 月，非本周新增"）。

## 防坑护栏（本项目最重要，必须遵守）
- **①搜索常把"旧闻 / 旧数据"说成"最近 / 本周"，模型还可能把检索片段缝合成看似真实的假新闻 + 假链接，小白零鉴别力。** 所以必须：先锁定日期范围 → 逐条核验发布日 → 标注口径 → 在开头提醒用户点链接核对。任何一条都不能省。
- **②区分"数据发布日"和"数据统计口径日"。** 一份 6 月发布的报告统计的可能是 4 月的数据；要分清"这条是本周发布的"和"这条统计的是本周的"，在简报里写清楚，别混为一谈。
- 拿不准发布日的条目，宁可不收，也不要硬塞进"本周"。

## 教学闭环（做完这样讲）
- "刚才你只说了一句：『出本周【某赛道】简报』。"
- "Agent 自动完成了：联网搜 + 多源核实 + 逐条核对发布日 + 成稿 + 给每条配解读。"
- "这件事原本要：每周自己刷各种资讯源 + 筛选去重 + 写解读，2–4 小时。"
- "以后你自己只要说这一句：『出本周【赛道】简报，锁定日期、逐条核验、标来源』。"
- "还能这样玩：① 改成日报 / 月报；② 只盯融资动态；③ 只盯政策变化。"

## Claude Code vs Codex（环境差异提醒）
- Claude Code：联网搜索 + 抓网页更顺手，本项目开箱即用。
- Codex：默认沙箱常常没有网络，跑本项目前要先确认联网已放开，否则搜不到任何东西。

## 进阶（问用户要不要）
- 配定时任务：每周一早上自动出本周简报，并推到飞书手机上看。
