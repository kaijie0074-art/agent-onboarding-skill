# 项目 05 · 名片一拍变官网（个人/公司网页几分钟生成）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
拍一张名片（或说几句自我介绍），几分钟就得到一个精美、手机能打开的官网/个人主页。

## 适合谁
创业者（公司官网/落地页）、大学生（求职个人主页/作品集）。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
- 公司版（推荐）：**「我把名片拍给你，帮我做成一个精美的、手机能打开的公司官网。先把名片上读到的信息（名字/公司/电话/邮箱/地址/业务）列出来给我确认，再开始做。」**
- 大学生版：**「根据我这些信息帮我做个精美的个人主页，突出专业/项目经历/联系方式，手机能打开。」**

## 环境自检（开始前，教练静默判断）
- 🟢 做网页**零准备**：纯天然就能生成自包含 HTML，不依赖任何工具/联网。
- 想正式上线拿到公网网址才需要工具：用 `vercel` 或 `gh`（GitHub Pages），没装就让 Agent 帮你装并引导你点一次浏览器登录；想要临时链接（零登录）可用 `cloudflared`。
- 做网页这一步永远不阻塞——先把 HTML 做出来，上线是后面"问用户要不要"的可选环节。

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/名片样例.png`（也有文字版 `名片信息.txt` 备用）。
- 真实数据：用户把名片照片直接拖进对话框，Agent 用视觉能力直接看图读字——**不用用户手敲任何文字**。
- 大学生没名片：让用户口述/粘贴专业、项目经历、联系方式即可，同样能做。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**先用我们的样例名片做一个看看，还是直接用你自己的名片/简历？**（AskUserQuestion）
2. 读图/读信息：样例就读 `assets/样例数据/名片样例.png`；真实就看用户拖进来的照片。
3. **先把读到的信息列出来让用户确认**（名字、公司/学校、职位/专业、电话、邮箱、地址、业务/项目、网址、其它共约 9 项）——防止模糊图误读，用户核对无误再往下做。
4. 生成 `index.html`：单文件自包含、手机自适应；结构含 hero 首屏 + 介绍 + 业务/项目 + 可点击的 `tel:` 电话和 `mailto:` 邮箱联系方式 + 适度动效与配色。
5. 本地起一个 HTTP 服务确认能正常打开（不要让用户去碰 `file://`），把效果回报给用户。
6. 问用户：**要不要把它上线，拿一个公网网址？**（AskUserQuestion：要永久网址 / 临时给人看一眼 / 先不上线）

## 成功标准
拿到一个能在手机打开、信息准确、好看的单页网站 HTML 文件。
（已实测：对真实名片图 9 项信息零误读，包括少见的 `.tech` 邮箱后缀。）

## 防坑护栏（必须遵守）
- 名片要拍清楚别反光；模糊或手写体可能认错电话/邮箱里的字母数字（l/I/1、O/0）——所以**必须先回显信息让用户核对**，确认后再生成。
- 浏览器会拦截 `file://` 本地文件，所以预览要用本地 HTTP 服务起（用户自己双击打开则不受这条限制）。
- 电话、邮箱一定做成 `tel:` / `mailto:` 可点击，手机上点一下就能拨号/发邮件。

## 上线（可选，先问用户要不要）
- 🟡 **永久网址**：用 `vercel` 或 `gh`（GitHub Pages）。部署 Agent 全程代跑，用户只需在浏览器点一次"同意登录"（一次性）。
- **临时给人看一眼**：用 `cloudflared` 起即时公网链接，连登录都免——但链接是临时的，实测偶发 Cloudflare 500。
- 诚实说明：永久上线必须登录某个托管账号（平台规则绕不开），但全程就点这一次，其余都由 Agent 代做。`[可逆]`

## 教学闭环（做完这样讲）
- "刚才你只说了一句话 + 拖了一张名片。"
- "Agent 自动完成了：看图读字、设计配色与文案、加动效、生成整个网站、本地验证能打开。"
- "这件事原本要：外包做个单页官网，3000–15000 元、3–10 天。"
- "以后你自己只要说这一句：『把这张名片做成官网』。"
- "还能这样玩：① 深色/科技风换风格；② 加客户 logo 墙；③ 大学生加作品集页。"

## Claude Code vs Codex（如适用，提一句）
- Claude Code 能直接看名片照片读字，"一拍即生成"。
- Codex 看图能力弱，通常要先手敲名片上的文字再做——多一步、更费事。

## 进阶（问用户要不要）
- 绑定你自己的域名，让公司官网/个人主页用上专属网址。
