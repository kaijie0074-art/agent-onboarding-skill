# 项目 04 · 自动回邮件（判断哪些要回 + 按你语气起草）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
Agent 帮你判断哪些邮件要回、按你的语气把回信草稿写好，你看一眼确认再发。

## 适合谁
每天要回不少邮件的创业者 / 职场人。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
- 🟢 零配置版（强烈建议新手先用）：**「我把要回的邮件粘给你，帮我判断哪些需要回，按我的语气把回信草稿都写好，先别发，让我过目。」**（用户把邮件内容粘贴或截图给 Agent → Agent 判断要不要回 → 起草，默认只存草稿不发送。）
- 🔴 全自动版（读真实收件箱，要先配置）：**「帮我装 himalaya 连上我的邮箱，自动读收件箱、把要回的挑出来起草，先存草稿别发。」**

## 环境自检（开始前，教练静默判断）
- 🟢 零配置版：无需任何东西，直接读用户粘贴/截图的邮件即可。
- 🔴 全自动版：用开源工具 `himalaya`（实测 `brew install himalaya`，v1.2.0 可用，任何 IMAP 邮箱都能接）+ 邮箱授权。
- 检查：`himalaya --version`。
- 🟡 缺了怎么办：先问一句（AskUserQuestion：装/不装），同意后自动 `brew install himalaya`。`[可逆，brew uninstall 可卸]`

## ⚠️ 不可代办的关键点（诚实说明）
连真实邮箱时，用户唯一必须亲手做、且谁都替不了的 2 步（邮箱服务商强制的安全闸门）：
1. 去邮箱网页后台开启 **IMAP**。
2. 生成 **"应用专用密码 / 授权码"**（需本人过两步验证）。

把授权码给 Agent 后剩下全自动，密码可存 Mac 钥匙串、之后零交互。

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/收到的邮件.txt`（含报价邮件 / 招聘系统通知 / 实习咨询三封）。
- 真实数据：
  - 零配置版：用户把要回的邮件内容粘贴或截图发给 Agent。
  - 全自动版：装好 `himalaya`、做完上面 2 步拿到授权码后，Agent 写好配置自动读收件箱。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**用样例邮件先体验（零配置）还是连你真实邮箱（要配置）？**（AskUserQuestion）
2. 若选零配置：直接读 `assets/样例数据/收到的邮件.txt`（或用户粘贴的邮件）→ 判断每封要不要回 → 按用户语气起草，默认只存草稿不发。
3. 若选全自动：先自检 `himalaya --version` → 缺则问装 → 引导用户做"开 IMAP + 拿授权码"这 2 步（明确告知这是唯一不可代办的环节及原因）→ Agent 写好配置 → 自动读信、挑出要回的、起草。
4. 全部默认**存草稿不发送**。回报成果：分好"要回 / 可忽略"的清单 + 已写好的草稿。

## 成功标准
用户拿到分好"要回 / 可忽略"并写好的草稿；演示 AI 正确忽略系统通知、认真回报价邮件、礼貌回实习咨询。

## 防坑护栏（必须遵守）
- 回复默认**只存草稿不发送**，必须用户确认（加 `--confirm-send`）才真发。
- 绝不替用户乱发邮件。

## 教学闭环（做完这样讲）
- "刚才你只说了一句：『帮我看收件箱，挑要回的起草，先别发』。"
- "Agent 自动完成了：判断哪些要回 + 按你语气起草 +（全自动版）读信、归档。"
- "这件事原本要：一封封读、想措辞、打字，每天半小时起。"
- "以后你自己只要说这一句：『看收件箱挑要回的起草，先别发』。"
- "还能这样玩：给常见问题设白名单，命中就自动回。"

## 进阶（问用户要不要）
- 各家邮箱（QQ / 163 / Gmail / Outlook）接入细节不同，可让 Agent 参考实测说明逐家配置 IMAP 地址、端口与授权码获取入口。
