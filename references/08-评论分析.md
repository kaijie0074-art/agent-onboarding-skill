# 项目 08 · 用户评论分析（一堆评论→几分钟出"用户之声"报告+图表）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
一堆用户评论丢进去，几分钟拿到一份"用户之声"报告 + 图表，告诉你大家最不满什么、最该先修什么。

## 适合谁
有用户反馈要分析的创业者、产品、运营——手里攒着一堆评论却没时间逐条读。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
**「帮我分析这些用户评论，做一份报告：好评差评占比、高频问题归类排序、最满意的点、最该优先修的 Top3，能出图就出图——画图用系统中文字体，画完打开图自己检查中文没乱码再给我，缺 matplotlib 你自己装。」**

## 环境自检（开始前，教练静默判断）
- 🟡 能力需求：画图要 Python 的 `matplotlib`。
- 检查：`python3 -c "import matplotlib"`。
- 缺了怎么办：先征得同意，再自动 `pip3 install matplotlib`。`[可逆]`
  - 可能遇到 PEP668"外部管理环境"拒装（系统 Python 不让直接装包）——这时改用虚拟环境，或加 `--break-system-packages`，教练自己处理，不要把报错甩给用户。

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/用户评论.csv`（15 条，带日期/渠道/评分/内容）。
- 真实数据：让用户把导出的评论 csv 拖进来，或直接粘贴文本、发截图。

## 带练步骤（一步一句，做完回报再走下一步）
1. 先问用户：**用样例评论先看效果，还是分析你自己的评论？**（AskUserQuestion）
2. 读取 csv（样例或用户的）。
3. 逐条判断情感（好评/差评/中性）。
4. 把差评里的问题归类，按严重度排序。
5. 找出"用户最满意的点" + "最该优先修的 Top3"。
6. 出中文图表（情感占比饼图 + 高频问题柱状图）。
7. **画完回读图片自检中文没乱码**（确认标题/坐标不是方框 □□□）。
8. 出报告（含图），回报成果路径。

## 成功标准
报告结论正确（情感占比对、Top 问题排序对），图表中文不乱码。
已实测：自动揪出 Top1 是"闪退（疑似版本回归 bug）"，其紧急度是第二名的 5 倍。

## 防坑护栏（本项目最重要，必须遵守）
- ① **中文乱码是头号坑**：matplotlib 默认字体不含中文，画出来的图标题/坐标全是方框 □□□，但程序不报错、照常说"成功"——小白完全察觉不到。所以必须：
  - 设系统中文字体（mac：`/System/Library/Fonts/STHeiti Medium.ttc`）；
  - 设 `axes.unicode_minus = False`（避免负号也变方框）；
  - **画完回读图片**，亲眼确认不是方框再交付。
- ② 看到 `Glyph missing` 警告 = 乱码信号，不能忽略，必须回去修字体。
- ③ 样本量小时，结论只能当趋势参考，别当成统计结论。

## 教学闭环（做完这样讲）
- "刚才你只说了一句：『分析这些评论出报告，能出图就出图，中文别乱码』。"
- "Agent 自动完成了：逐条判断情感、归类问题、按严重度排序、画中文图表、出报告。"
- "这件事原本要：人工读几百条评论、手工打标签、归类、再画图，半天到一天。"
- "以后你自己只要说这一句：『分析这些评论出报告，能出图就出图，中文别乱码』。"
- "还能这样玩：同一套方法对 15 条和 1.5 万条评论几乎一样快。"

## 进阶（问用户要不要）
- 定期分析 + 趋势对比：每周/每月跑一次，对比这期和上期的好差评占比、问题排名变化，看修复有没有奏效、有没有新问题冒出来。
