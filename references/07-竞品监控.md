# 项目 07 · 竞品监控日报（自动盯对手官网/定价/更新）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
每天自动帮你盯几个竞品的官网、定价、产品更新，汇总成一份带来源链接的日报，还给你行动建议。

## 适合谁
要盯对手的创业者、产品经理、运营。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
**「每天帮我盯 A、B、C 三个竞品，抓它们官网的定价页和产品更新，生成一份竞品监控日报。每条必须标来源链接、并注明是『官网实抓』还是『搜索来的』；抓不到的就如实写『未抓到』，绝对不要编。」**

## 环境自检（开始前，教练静默判断）
- 🟢 联网能力内置，零准备即可访问竞品官网、搜索交叉验证。
- 遇到国内动态站点（价格靠网页脚本动态加载的那种）需要浏览器工具（Playwright，用真实浏览器渲染网页后再抓）。没有就让 Agent 帮你装/启用浏览器能力。

## 准备输入
- 让用户说出 2–3 个竞品的名字或网址。
- 没有也没关系：用通用例子先演示，让用户看到效果再换成真实竞品。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**先拿两三个知名产品演示，还是直接盯你的真实竞品？**（AskUserQuestion）
2. 拿到竞品清单后，联网逐个访问各竞品的定价页 / 产品更新页。
3. 抓取每个竞品的：最新动态、当前定价、值得注意的点。
4. 遇到抓不到的动态站点（拿回来只有空标题、没有真实价格），改用浏览器工具（Playwright）渲染后再抓一次。
5. 生成日报：每个竞品一段（最新动态 + 定价 + 值得注意 + 1 条行动建议），每条都标来源链接、注明"官网实抓 / 搜索来的"，抓不到的如实写"未抓到"。文件名带日期。
6. 回报成果路径，并问：**要不要把这份日报推到你飞书手机上看？**（要 → 走项目 03 的飞书推送方式；不要 → 跳过）

## 成功标准
用户拿到一份带真实来源链接的日报：抓到的是真数据，抓不到的如实标注"未抓到"，全程没有编造。

## 防坑护栏（本项目最重要，必须遵守）
- **动态加载陷阱**：很多国内网站（飞书、语雀这类）的价格是网页脚本动态加载的，普通联网抓不到。Agent 可能"静默"地拿不到，却用记忆脑补一个价格出来 → 所以必须强制要求"标来源、抓不到就说未抓到"。
- ✅ **去人工化解法（已实测）**：遇到抓不到的动态站点，加一句"用浏览器工具（Playwright）渲染后再抓"。实测：普通联网拿语雀价格只得到空标题，换 Playwright 后成功抓到真实价 ¥0 / ¥99 / ¥299（每人每年）。
- **单日只能拿当前价**：要识别"涨没涨价 / 出没出新功能"，需要每天存一份快照做对比，单次抓取看不出变化。

## 教学闭环（做完这样讲）
- "刚才你只说了：『盯 A、B、C 三个竞品，抓定价和产品更新做成监控日报』。"
- "Agent 自动完成了：逐个访问竞品官网、抓取定价和更新、汇总成日报、每条标来源、给出行动建议。"
- "这件事原本要：每天逐个翻竞品官网，40–60 分钟，还容易漏掉对手『悄悄涨价 / 发了新功能』。"
- "以后你自己只要说这一句：『盯这几个竞品做监控日报，标来源、抓不到就说』。"
- "还能这样玩：① 只盯价格变化；② 只盯新功能上线。"

## Claude Code vs Codex（同样一句话，两边表现不同）
- **Claude Code**：联网开箱即用；遇到反爬还能自动换搜索交叉验证，拿不准的会标"搜索来的"。
- **Codex**：默认沙箱环境常常没有网络，这个项目会直接卡在第一步抓不到数据。

## 进阶（问用户要不要）
- 配定时任务每天自动跑。
- 存历史快照，自动做价格 diff（对比出"今天比昨天涨了/降了"）。
- 跑完自动推到飞书。
