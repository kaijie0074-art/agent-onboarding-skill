# 项目 S4 · 学生项目·自动准备竞赛材料（对齐评审要求的初稿）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
说清你们参加哪个比赛、项目是什么方向，几分钟拿到一套对齐该赛事评审要求的材料初稿。

## 适合谁
参加各类竞赛的大学生团队（创业大赛、数学建模、编程赛等）。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
**「我们参加【写清楚是哪个竞赛】，项目是【一句话方向】。先联网查清这个竞赛官方规定要交什么材料（是论文、商业计划书、还是代码？），按它真正要的来做，别套模板。联网查评审维度和真实市场/技术数据，标好来源，需要我们团队填真实信息的地方用【待填】标出来。」**

## 环境自检（开始前，教练静默判断）
- 🟢 联网调研内置，零准备即可生成全套材料初稿。
- 想把 PPT 大纲变成真正的 `.pptx` 文件：需要 Python 库 `python-pptx`，没装就让 Agent 跑 `pip3 install python-pptx`（缺 pip 或遇环境限制时 Agent 自己处理）。

## 准备输入（先样例后真实）
让用户说清楚两件事：
- ① 哪个竞赛（写全称，如"中国国际大学生创新大赛"）。
- ② 项目方向（一句话）。
- 没有具体的就用样例先演示：**"互联网+创业大赛 + 校园二手书平台"**。

## 带练步骤（一步一句，做完回报再走下一步）
1. 先问用户：**先拿一个示例竞赛跑一遍看效果，还是直接准备你们真实的竞赛？**（AskUserQuestion）
2. **先联网查清这个竞赛官方规定的法定交付物**——不是凭印象，是查官方简章。确认它到底要论文、商业计划书、还是代码。
3. 按它真正要的生成材料，别套用其他赛道的模板：
   - 创业赛 → 商业计划书 + 路演 PPT + 路演稿。
   - 数学建模赛 → 论文骨架 + 模型，**不要** PPT、不要路演稿。
   - 编程赛 → 代码。
4. 联网查评审维度和真实市场/技术数据，材料里**标清来源**。
5. 凡是需要团队填的真实信息（姓名、试点数据、成交单数等），用 **【待填】** 标出来。
6. （可选）用 `python-pptx` 把 PPT 大纲生成真正可编辑的 `.pptx`。

## 成功标准
材料切题（符合该赛事真正要的产出物）、有真实数据来源、标清了哪里要团队自己填。
已实测：创业赛例子产出对齐评审维度、带真实市场数据来源的全套材料；用 `python-pptx` 几秒生成 11 页中文不乱码、可编辑的 pptx。

## 防坑护栏（本项目最重要，必须遵守）
- **不同竞赛要的东西完全不同**：创业大赛要商业计划书+路演 PPT；数学建模赛要论文+代码、根本不要 PPT 和路演稿；编程赛要代码。→ **必须先查清赛事法定交付物**，别让 Agent 机械套用创业模板，产出文不对题的东西（评委不收 = 白干）。
- **真实性是红线**：财务/市场数据是示范估算，团队真实信息（姓名/试点数据/成交单数）必须自己填。评委现场追问、编造极易翻车。
- **出真 pptx 时中文易乱码**：必须同时把 latin / ea / cs 三处字体都设为 `PingFang SC`，否则中文显示成乱码方框。

## 教学闭环（做完这样讲）
- "刚才你只说清了：参加哪个竞赛、项目是什么方向。"
- "Agent 自动完成了：联网查清赛事要求、按真正需求生成全套材料、标好来源、把要团队填的地方标【待填】。"
- "这件事原本要：从零做一套材料，7–12 天。"
- "以后你自己只要说这一句：『参加 X 竞赛做 Y 方向，先查清要交什么别套模板，标来源标待填』。"
- "还能这样玩：① 只出路演稿；② 只出论文骨架；③ 把大纲变成真 pptx。"

## Claude Code vs Codex
- 调研 + 中文长文：**Claude Code** 更稳。
- 把大纲转 pptx 这类纯代码活：Codex 也能胜任。

## 进阶（问用户要不要）
- 让 Agent 按评审维度给材料逐项打分，并给出改进建议。
