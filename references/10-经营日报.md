# 项目 10 · 经营日报（每日销售数据自动算成给老板看的日报）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
丢一份每日销售数据，几秒拿到一份给老板看的经营日报——核心指标、环比涨跌、异常、亮点、行动建议，全部算好。

## 适合谁
做电商/零售、或任何有每日销售数据的创业者、店主。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
**「用这份经营数据，生成一份给老板看的经营日报：销售额、订单、客单价、退款率、获客 ROI，跟昨天对比涨跌，自动找出异常和亮点，给 1–3 条今日行动建议。所有数字用代码精确计算、不要心算，并在报告里写明每个指标的计算公式。」**

## 环境自检（开始前，教练静默判断）
- 🟢 零准备。给一份 csv 即可，所有指标用 Python 现场算（pandas/标准库都行），不需要装任何额外工具。

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/经营数据.csv`（含两天、多渠道的订单数 / 销售额 / 退款 / 新客数 / 广告花费）。
- 真实数据：让用户从各平台后台（天猫/抖音/京东/有赞等）导出当天的销售数据，合成一张 csv 拖进来。字段对齐样例即可。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**用我们的样例数据先看效果，还是用你自己今天的数据？**（AskUserQuestion）
2. 读 csv。
3. 用 Python 精确计算各指标：客单价＝销售额／订单数、退款率、ROAS（获客 ROI）、以及每项相对昨天的环比涨跌。**全部用代码算，不心算。**
4. 拆解各渠道表现（按渠道分别算同一套指标）。
5. 自动发现异常（如某渠道退款率畸高、某渠道获客成本明显偏贵）和亮点。
6. 给出 1–3 条今日可执行的行动建议。
7. 输出经营日报 md（+docx）：指标 + 环比 + 异常/亮点 + 建议 + **每个指标的计算公式**。文件名带日期。

## 成功标准
数字算对（可人工抽查核对）、自动揪出人眼容易漏的异常、给出可执行建议。
已实测：数字人工核对零差错；自动发现"天猫退款额环比激增 75%、抖音是全店最贵流量（ROAS 仅 4.39）"。

## 防坑护栏（本项目最重要，必须遵守）
- **必须"用代码精确计算 + 写明公式"是硬约束。** 不加这句、且数据量少时，Agent 可能"心算"——除法、百分比极易算错；而用户正是因为不会算才找它、根本看不出错。所以咒语里"用代码精确计算、不要心算、写明公式"一个字都不能省。
- **写清每个指标口径**，避免歧义：ROAS＝销售额／广告费；退款率分母要说明白是按销售额还是按订单数。报告里把公式列出来，老板和用户才能对账。
- **除零保护**：某渠道某天数据为 0（如没投广告、没订单）时不能让计算崩溃，要优雅处理（标注"无数据/不适用"而不是报错）。

## 教学闭环（做完这样讲）
- "刚才你只说了一句：『用这份数据出经营日报』。"
- "Agent 自动完成了：用代码算全部指标、算环比、找异常、给建议，并写明每个公式。"
- "这件事原本要：每天导数据 + Excel 透视 + 手算指标 + 找异常 + 写点评，30–60 分钟，而且除法还容易算错。"
- "以后你自己只要说这一句：『用这份数据出经营日报，用代码算别心算、写明公式』。"
- "还能这样玩：① 出周报/月报；② 多店对比。"

## 进阶（问用户要不要）
- 固定数据源 + 定时任务：每天自动跑出经营日报并推送到飞书 / 发邮件给老板，人不用动手。
