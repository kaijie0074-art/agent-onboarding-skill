# 学生项目 S1 · 自动完成作业（重在学会不是照抄）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
把作业发给 Agent，它写答案并真实运行验证，还逐题讲思路——一个随叫随到的私人助教。

## 适合谁
大学生（尤其编程/理工科作业）。

## 核心咒语（最终要教会用户说的那句话）
**「把这份作业做一下，每道题写出答案、真实运行代码验证并把运行结果贴出来，并讲清楚思路，整理成我能看懂的文档。」**

## 环境自检（开始前，教练静默判断）
- 🟢 不需要任何插件：用内置跑代码能力 + 你电脑的 `python3` 就能真实运行验证。
- 如果装了 pandoc，可顺手把整理好的文档转成 Word，方便用户在手机/电脑上看；没装就跳过（不影响交作业）。
- 检查：`python3 --version`（确认能跑代码；缺了让 Agent 引导安装）。

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/学生作业题.md`（数据结构课，含编程题/算法分析/简答）。
- 真实数据：学生拍照、截图、粘贴文字，或直接把作业文件拖给 Agent。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**先用样例作业先体验，还是做你自己的作业？**（AskUserQuestion）
2. 理解题目：逐题读懂要求（编程题要什么输入输出、算法分析要分析什么、简答考什么概念）。
3. 写代码并真实运行：用 `python3` 实际跑一遍，确认结果正确，把真实运行输出贴出来——不是凭记忆写"应该输出 X"。
4. 写分析题和简答题的答案。
5. 整理成规范文档：每段带"思路 / 为什么这样做"的讲解，像助教讲题一样。
6. 文档开头加 AI 辅助声明（见护栏）。回报成果路径，并问：**要不要转成 Word 方便你看？**

## 成功标准
答案正确、代码真实运行过（贴出真实输出）、讲清思路。
- 已实测：栈实现真跑出 `[3, 2, 1]`；两数之和暴力 + 哈希两种解法，6 组用例（含空数组、负数等边界）全部跑通验证。

## 防坑护栏（本项目最重要 = 学术诚信，必须遵守）
- **正确用法是当助教，不是代考**：看懂思路、能自己讲清楚再交，遇到不懂就追问 Agent。很多学校把"提交 AI 作业且不声明"视为学术不端，直接照抄有挂科/处分风险。
- **文档开头必须加声明**："本答案由 AI 辅助生成，建议理解后再提交，重在学会而非照抄。"
- **引导学生把它当题解读**：重点看「思路」和「复杂度为什么这样算」；可以让 AI 把某一行代码讲得更细，或换一组数据让自己先做、再对答案。

## 教学闭环（做完这样讲）
- "刚才你只说了一句：『做这份作业、跑通验证、讲清思路』。"
- "Agent 自动完成了：写代码 + 真实运行验证 + 逐题讲思路 + 整理成规范文档。"
- "这件事原本要：自己做一份数据结构作业 1.5–2 小时，还常卡在边界情况上。"
- "以后你自己只要说这一句：『做这份作业、跑通验证、讲清思路』。"
- "但记住——价值不在省时间，而在它是你的私人助教：学会了比交了更重要。"
- "还能这样玩：① 让它只讲思路、不给完整答案，逼你自己写；② 你写完，让它来批改。"

## Claude Code vs Codex
跑代码两者都行。Claude Code 在中文文档整理和讲思路上更细腻。

## 进阶（问用户要不要）
让 Agent 出几道同类练习题，帮你巩固这个知识点。
