# 项目 02 · 文章转短视频（一篇文章变竖屏带字幕带配音的 mp4）

> 教练读完本文件后，照"带练步骤"一步步执行。一次只推进一步。

## 一句话目标
丢一篇文章，几分钟拿到一条能直接发的竖屏短视频（带字幕、配音）。

## 适合谁
做内容 / 自媒体 / 带货的创业者。

## 核心咒语（最终要教会用户说的那句话，已加防坑约束）
- **「把这篇文章转成一条竖屏短视频，配好字幕和旁白，直接生成 mp4。做之前先检查 ffmpeg 和 Pillow 这些工具装没装，缺了你自己装好，中文字幕别用乱码字体。」**

## 环境自检（开始前，教练静默判断）
- 能力需求：`ffmpeg`（视频合成）+ Python `Pillow`（生成字幕图）。
- 检查：`ffmpeg -version` 和 `python3 -c "import PIL"`。
- 🟡 缺了怎么办：先征得同意（AskUserQuestion：装/不装），同意后自动 `brew install ffmpeg`、`pip3 install pillow`。`[可逆]`

## 准备输入（先样例后真实）
- 样例（先跑通、零风险）：`assets/样例数据/待转视频文章.md`。
- 真实数据：用户把文章拖进来，或贴链接 / 直接贴文字。

## 带练步骤（一步一句，做完回报再走下一步）
1. 告诉用户这个项目会得到什么（1 句）。问他：**先用我们的样例文章跑一遍看效果，还是直接用你自己的文章？**（AskUserQuestion）
2. 自检环境：缺 ffmpeg / Pillow 则问装（AskUserQuestion），同意后自动装。
3. 把文章改写成口播脚本，并拆分镜（每个分镜一句话 + 对应字幕）。
4. 用 PIL 生成竖屏配字幕图（每个分镜一张 1080x1920 的 PNG，中文字直接渲染进图里）。
5. Mac 用 `say` 生成中文旁白音频。
6. ffmpeg 把字幕图 + 旁白合成带淡入淡出的 mp4。
7. ffprobe 验证可播放，回报路径，并问：**要不要把这条视频推到你飞书手机上看？**

## 成功标准
用户拿到一条 1080x1920 竖屏、中文字幕无乱码、能正常播放的 mp4。

## 防坑护栏（必须遵守）
- brew 装的 ffmpeg 可能没带 drawtext 字幕滤镜 → 不要硬上 drawtext，改用"PIL 把字渲染进 PNG 再合成"绕开。
- 中文字体用系统 STHeiti（`/System/Library/Fonts/STHeiti Medium.ttc`）避免乱码；别用 PingFang 顶层路径（不存在）。
- 合成时必须加 `-pix_fmt yuv420p`，否则手机上播放会黑屏。
- Mac 的 `say` 配音仅 macOS 有；Win/Linux 要换配音工具（如实告诉用户即可）。

## 教学闭环（做完这样讲）
- "刚才你只说了一句话：『把这篇文章转成竖屏短视频』。"
- "Agent 自动完成了：把文章改写成口播脚本、生成竖屏字幕图、配好旁白、合成 mp4、验证能播放。"
- "这件事原本要：自己剪 2–4 小时。"
- "以后你自己只要说这一句：『把这篇文章转成竖屏短视频带字幕配音生成 mp4』。"
- "还能这样玩：换音色 / 加背景音乐 / 换配色。"

## 进阶（问用户要不要）
- 批量把多篇文章转成一个系列短视频。
