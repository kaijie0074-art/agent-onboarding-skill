# 《数据结构》课程作业（第6周）

## 题目一（编程，40分）
用 Python 实现一个栈（Stack），要求支持 push、pop、peek、is_empty 四个方法，并写一个测试函数验证：依次压入 1,2,3 后，连续 pop 三次应依次得到 3,2,1。

## 题目二（算法分析，30分）
给定一个整数数组，编写函数判断其中是否存在两个数之和等于目标值 target。请：
1. 写出暴力解法并分析时间复杂度；
2. 写出更优解法（哈希表）并分析时间复杂度；
3. 用例子说明两种解法的差异。

## 题目三（简答，30分）
简述数组和链表在"随机访问"和"插入删除"两个操作上的性能差异，并各举一个适合用数组、适合用链表的真实场景。
